结算订单金额溯源

定位支付 / 退款关联导致的订单金额虚高：上传三表 JSON，运行只读聚合 SQL， 逐组逐单展开参与 SUM 的关联行组合、计入次数与贡献金额。

1. 上传三表 JSON

格式：{"orders": [...], "payments": [...], "refunds": [...]}。 orders 每行含 order_id（非空）与 amount（非空数值）； payments / refunds 每行含唯一行号 pay_id / refund_id 及 order_id； 三表合计不超过 500 行，允许额外标量字段（如 orders.channel）。

2. 输入只读 SQL

以 orders 为主表，所有表须显式别名；仅支持 INNER/LEFT JOIN ... ON、WHERE、 按字段 GROUP BY、一个 SUM(orders.amount)。不支持子查询、窗口函数、DISTINCT、 HAVING、ORDER BY、LIMIT 等。
